## Tools without a direct endpoint

* `diagnose_connectivity` : 4-step network diagnostic (DNS, TCP, HTTP, daemon state).
* `get_server_safety_config` : safety configuration of the MCP server.
* `get_perception_status` : state of the WebRTC stream and of the local voice models.

## Media stream outside the OpenAPI

The daemon also runs a GStreamer `webrtcsink` media server with its signalling server (`ws://<host>:8443`, producer `reachymini`). It broadcasts the camera video and the microphone audio. This stream does not appear in the OpenAPI; it was identified in the daemon code (`reachy_mini/media/media_server.py`) and validated on the real robot from the container. It feeds `capture_image` and `listen`. Speech recognition (faster-whisper) and speech synthesis (Piper) run locally in the container.
